# 記事プレビューUI改善 - 実装ガイド

## 🎯 改善の目的

カード一覧から記事を読むまでの動線を改善し、ワンタップで記事が読めるようにします。

### Before（現在）
```
カード一覧
  ↓ タップ
記事詳細画面（メモ・タグ表示）
  ↓ 「記事を読む」ボタンタップ
WebView記事表示
```
**問題**: 記事を読むまでに2タップ必要

### After（改善後）
```
カード一覧
  ↓ タップ（1回）
WebView記事表示 + ツールバー
  ├─ 📝 メモ追加
  ├─ 💭 引用メモ
  ├─ ✅ TODO追加
  ├─ ⭐ お気に入り
  └─ 📋 詳細画面へ
```
**改善**: ワンタップで記事が読める

## 🎨 UI設計

### WebView記事表示画面（新デザイン）

```
┌─────────────────────────────────┐
│ ← 戻る                      ⋮   │ ← ナビゲーションバー
├─────────────────────────────────┤
│                                 │
│                                 │
│     記事コンテンツ              │
│     （WebView）                 │
│                                 │
│                                 │
│                                 │
├─────────────────────────────────┤
│  📝   💭   ✅   ⭐   📋        │ ← ツールバー
│ メモ 引用 TODO お気に 詳細      │
└─────────────────────────────────┘
```

### ツールバーアクション詳細

1. **📝 メモ**: モーダルでメモ追加画面を表示
2. **💭 引用**: テキスト選択モードに切り替え
3. **✅ TODO**: TODOメモを素早く追加
4. **⭐ お気に入り**: トグル（即座に反映）
5. **📋 詳細**: 記事詳細画面に遷移
