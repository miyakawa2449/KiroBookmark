# Task6 修正2: 記事詳細画面のブックマークボタン削除

## 🎯 修正の目的

記事詳細画面に表示されている不要なブックマーク追加ボタンを削除します。詳細画面は既にブックマーク済みの記事のみ表示されるため、このボタンは不要です。

---

## 🔍 事前調査

まず、ArticleDetailViewにブックマーク追加ボタンが存在するか確認してください。

**ファイル**: `KiroBookmark/Views/ArticleDetailView.swift`

### 確認ポイント
1. ブックマーク追加ボタンのUI要素が存在するか
2. ボタンのアクション（onTapGesture、Button、など）
3. 関連するViewModel内のメソッド

---

## 🔧 修正内容

### パターンA: Buttonコンポーネントの場合

**削除対象の例**:
```swift
Button(action: {
    viewModel.addToBookmark()
}) {
    HStack {
        Image(systemName: "bookmark")
        Text("ブックマークに追加")
    }
}
```

**修正方法**: このButton全体を削除

---

### パターンB: カスタムビューの場合

**削除対象の例**:
```swift
HStack {
    Image(systemName: "bookmark")
        .onTapGesture {
            viewModel.addToBookmark()
        }
    Text("ブックマークに追加")
}
```

**修正方法**: このHStack全体を削除

---

### パターンC: ツールバーアイテムの場合

**削除対象の例**:
```swift
.toolbar {
    ToolbarItem(placement: .navigationBarTrailing) {
        Button(action: {
            viewModel.addToBookmark()
        }) {
            Image(systemName: "bookmark")
        }
    }
}
```

**修正方法**: このToolbarItem全体を削除（他のToolbarItemがある場合は該当部分のみ削除）

---

## 🧹 関連コードのクリーンアップ

### ViewModel内の不要なメソッド削除（オプション）

もし `addToBookmark()` メソッドがArticleDetailViewModel内に存在し、他で使用されていない場合は削除を検討してください。

**確認方法**:
1. ArticleDetailViewModel.swiftを開く
2. `addToBookmark` メソッドを検索
3. 他の場所で使用されていないか確認
4. 使用されていなければ削除

**削除例**:
```swift
// 削除対象
func addToBookmark() {
    // ブックマーク追加ロジック
}
```

## 📝 実装時の注意点

1. **段階的削除**: まずUI要素のみ削除し、ビルドして確認
2. **コメント残し**: 削除理由をコメントで残すことを推奨
   ```swift
   // Task6 User Test Fix: ブックマーク追加ボタンを削除
   // 理由: 詳細画面は既にブックマーク済みの記事のみ表示されるため不要
   ```
